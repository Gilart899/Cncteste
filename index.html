Construa sua própria CNC 3.0 com Arduino

16/06/2020 /

Seja bem vindo, projetista fora do comum, ao tutorial de como fabricar e montar sua própria CNC com Arduino do absoluto zero em casa. Neste tutorial você vai aprender a construir a CNC 3.0, que possui área de trabalho de 39x74cm e adaptação para motores de passo NEMA 17. Este é um modelo robusto, com precisão e agilidade, desenvolvida por mim para manter o estilo “faça você mesmo” com baixo custo.

Se você é iniciante, ou quer construir uma CNC menor, com área de 20x20cm, clique no botão abaixo para ir ao tutorial de como fazer a CNC 2.1:

CLIQUE AQUI PARA CONHECER A CNC 2.1

Este tutorial já está completo, e todas as informações que você precisa para montá-lo, como substituições, tipo das peças, medidas, valor aproximado, está tudo aqui. Não comercializamos mais peças de CNC, e também não fazemos projetos externos.

Especificações do motor de passo que utilizei:

  • Flange: NEMA 17;
  • Código: SM1.8-A1740CH-CS;
  • Tensão: 4Vcc; 
  • Torque Estático: 2.5 Kgf/cm; 
  • Diâmetro do eixo: 5.0mm; 
  • Comprimento da Carcaça: 40mm; 
  • Corrente para ligação em paralelo: 1.2A;
  • Peso: 0,4 kg; 
  • Quantidade de Fios: 4 (2 fases); 
  • Resolução: 200PPR / 1.8º;
  • Temperatura de Trabalho: -20°C à 50°C; 
  • Classe de Isolação: B.

Outras ferramentas utilizadas:

  • Alicate;
  • Fita isolante;
  • Ferro de solda;
  • Estanho;
  • Chave philips e fenda;
  • Abraçadeiras de Nylon;
  • Fios elétricos;
  • Cola a base de cianoacrilato (ex: super bonder).

Como baixar o GRBL:

No link abaixo você irá baixar a pasta pronta para instalar na IDE do Arduino, sem o controle PWM do Spindle, onde fiz a alteração na linha //#define VARIABLE SPINDLE // Default enabled. Comment to disable. Ao adicionar as duas barras “//” eu transformo essa linha num comentário fazendo com que ela deixe de ser executada no código.

  • GRBL Master com linha de código alterada por mim – Clique aqui.
Caso não queira baixar a pasta pronta e prefira fazer todo o processo, clique no link abaixo e siga as instruções:

  • GRBL Master sem alteração – Clique aqui.
  • Visualizar os pinos do GRBL no Arduino – Clique aqui.
Como localizar a linha a ser editada:

1º – Abra a pasta grbl-master, grbl, depois abra o arquivo config com o bloco de notas, pressione CTRL+F e cole a linha abaixo:

#define VARIABLE SPINDLE // Default enabled. Comment to disable.
 
2º – O bloco de notas irá localizar a linha, e então você deve inserir o // no início da linha ficando assim:
 
//#define VARIABLE SPINDLE // Default enabled. Comment to disable.

3 ° – Depois, salve e instale a biblioteca na IDE do Arduino, ou baixe a primeira pasta pronta e fique tranquilo.
